# docs/ — Project Documentation

## Role
Document research methodology, architecture design, and findings.

## Core Documents
- `architecture.md`: Project code architecture description
- `methodology.md`: Research methodology (why this approach was chosen)
- `findings/`: Per-experiment findings summaries

## Rules
- Update `architecture.md` when code changes affect architecture
- Write summary document in `findings/` upon completion of each experiment series
- Documents should be detailed enough for other researchers to read and reproduce
